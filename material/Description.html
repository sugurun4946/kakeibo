Flutter × C++ FFI連携 超入門ガイド

〜 家計簿アプリの税込計算を例に、仕組みをスッキリ理解する 〜

1. FFI（Foreign Function Interface）とは？

FFIとは、一言でいうと「別のプログラミング言語で書かれたプログラムを、直接呼び出すための仕組み」です。

今回の例では、ユーザーが操作する綺麗な画面（UI）は Flutter (Dart) で作り、裏側の重い計算やデータベース処理（SQLite）は得意な C++ に任せる、という「いいとこ取り」を実現しています。

2. データが往復する全体の流れ

アプリの画面で「接続テストボタン」を押した瞬間、データは以下のように瞬時に往復しています。

① Flutter画面（ユーザーがボタンをタップ）
「1000円、税抜区分:2、税率:2」というデータを抱えて、計算をリクエストします。
② Dartの世界（型データの変換）
Dartの数値を、C++が理解できる形（ffi.Int32）に通訳して、国境（メモリの境界線）を越えます。
③ C++の窓口（extern "C"）
C言語スタイルのシンプルな窓口でデータを受け取り、内部のC++クラス（ExpenseManager）に処理を投げます。
④ C++のコアロジック（計算実行）
C++が「1000円 × 1.1 = 1100円」と超高速で計算し、結果を窓口に返します。
⑤ Flutter画面に到着
Dartの型に戻された「1100」という結果を受け取り、画面やログに「1100円」と表示されます！

3. 最も重要なキーワード：extern "C" の役割

C++には、同じ名前の関数を何個も作れる便利な機能（オーバーロード）があるため、コンパイルすると関数名が自動的に複雑な文字列（例: _Z5printi）に書き換えられてしまいます。これを名前修飾（マングル）と呼びます。

しかし、Flutter（Dart）はシンプルな「C言語のルール（C ABI）」しか読めません。そこで、C++側に以下の命令を出します。

C++
extern "C" {
    // この中は「C言語のルール」でビルドして！名前を変えないで！
    int c_get_amount_including_tax(int price, int type, int rate) {
        ExpenseManager manager;
        return manager.getAmountIncludingTax(price, type, rate);
    }
}
💡 初心者向けポイント:
extern "C" をつけることで、バイナリ（.soファイル）の中に c_get_amount_including_tax という名前がそのまま綺麗に残ります。だからDartから名前で一発検索できるようになります！

4. Dart側での受け入れ態勢（型定義とロード）

Dart側では、C++の関数を呼び出すために「C++の世界での型」と「Dartの世界での型」の2つをセットで定義（typedef）します。

Dart
// 1. C++の世界の型ルール（ffiの型を使う）
typedef CGetAmountFunc = ffi.Int32 Function(ffi.Int32, ffi.Int32, ffi.Int32);

// 2. Dartの世界での型ルール（いつもの int 型）
typedef DartGetAmountFunc = int Function(int, int, int);

void testCplusplusConnection() {
    // ライブラリ（.so）を読み込む
    final dylib = ffi.DynamicLibrary.open('.../libnative_expense.so');

    // 名前を頼りに関数を見つけ出し、Dartの関数として合体させる！
    final DartGetAmountFunc getAmountIncludingTax = dylib
        .lookup<ffi.NativeFunction<CGetAmountFunc>>('c_get_amount_including_tax')
        .asFunction();

    // あとは普通のDartの関数として使うだけ！
    int result = getAmountIncludingTax(1000, 2, 2); 
}

5. まとめと今後のメリット

  • 速度が圧倒的： データの変換を最小限にしてメモリを直接叩くため、動作が非常に高速です。
  • C++の資産が活きる： 画面はFlutterで今風に作りつつ、過去に作ったC++のロジックや、SQLiteデータベースをそのまま合体させられます。

今回は「数値の計算」でしたが、このパイプラインさえ繋がってしまえば、今後は「C++でデータベースに保存する」「C++から履歴の一覧を読み出す」といった複雑な機能も、同じ流れでどんどん追加していくことができます！
